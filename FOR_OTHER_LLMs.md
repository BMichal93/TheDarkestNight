# For Other LLMs — session handoff notes

This file is a **scratch handoff pad**, not a permanent record (that's what
`RECENT_CHANGES.md` and `CHANGELOG.md` are for). When a Claude Code session is
running low on context/tokens mid-task, it updates this file with enough
detail for the *next* session (possibly a different LLM/agent) to pick up
without re-deriving everything from scratch.

## How this file is maintained

- **Update it whenever a session is approaching the end of its available
  tokens** and work is still in progress: what you were asked to do, what
  you've discovered so far, what you've already changed, and exactly what's
  left.
- **At the start of a session, check this file.** If it has notes and nothing
  has changed since they were written (no new user request, no relevant code
  drift), just pick up where it left off.
- **If the notes are stale/no longer relevant** (the task finished, the user
  moved on, or the described state no longer matches the repo), delete the
  notes and leave this file back at the template below before writing new
  ones.
- Keep entries short and practical — file paths, what's done, what's not,
  open questions for the user. This is not a changelog and not documentation;
  don't let it accumulate history the way `RECENT_CHANGES.md` does.
